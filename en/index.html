One page.
Open for business.

One Page Go is a Taiwan-based service that builds single-page web apps for small businesses, with four plans: micro e-commerce, online booking, group-buy management and event ticketing. It runs on the free tiers of GitHub Pages, Cloudflare Workers and D1, so after a one-time payment from NT$2,500 (about US$78) there are no monthly fees, ever. Compared with subscription store platforms it saves more than NT$27,000 over two years, and every merchant owns a dedicated database that can be exported in full at any time, with no platform lock-in.

FAQ

Frequently asked questions

One Page Go builds single-page web apps for small businesses in Taiwan. Four templates: micro e-commerce, online booking, group-buy management and event ticketing. Pay once from NT$2,500 (about US$78) and there are no monthly fees after launch. Every merchant gets a dedicated database that is never shared with anyone else.

One Page Go is a one-time payment with no monthly, yearly or renewal fees. Event ticketing page NT$2,500, group-buy manager NT$3,000, booking with capacity control NT$3,500, micro e-commerce shop NT$4,000. After launch the site runs on free hosting and a free database, so the running cost is zero.

One Page Go is built on a free stack: GitHub Pages for web hosting (free), Cloudflare Workers and D1 for the backend and database (free tier), and Resend for email notifications (free quota). Every layer is on a free plan, so there are no hosting or maintenance fees after launch.

All orders, members and bookings are stored in your own Cloudflare D1 database. Each merchant has a separate database that is never shared with other merchants, and you can request a full export or backup at any time.

The main differences are cost structure and data ownership. Monthly platforms usually start at NT$1,299 a month, which adds up to over NT$31,000 in two years, and your data stays locked on their servers. One Page Go is a one-time NT$2,500-4,000 with nothing to pay afterwards, and you own a dedicated database you can export in full, with no platform lock-in.

From a confirmed brief to a live site takes as little as 3 days. The flow is: fill in the brief → confirm content and sign → pay → build and hand over → we help you set it up and go live.

Existing customers submit changes through the project change page. Each change request is NT$500 (about US$16) and covers text, image and colour adjustments, completed in as little as 1 day after submission.
