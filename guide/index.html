Setup Guide

歡迎！接下來要做什麼？

感謝您購買 One Page Go 方案，好消息是：幾乎不用設定

  1. 網頁託管 — 我們負責
    網頁由我們部署與維護，您不需要建立任何帳號。
  2. 商家專屬資料庫 — 我們負責
    訂單、會員等營運資料存放在您專屬的雲端資料庫，由我們建置（免費），可隨時完整匯出。重視資料主權？也可以部署在您自己的 Cloudflare 帳號（見「資料庫設定」）。
  3. 寄信設定 — 唯一需要您參與的一步
    網站要寄訂單通知與驗證碼給您的客戶，需要一把寄信金鑰。二選一：自己申請（免費）或寄信託管（NT$199／月）。
為什麼寄信要用您的金鑰？
寄信額度與寄件身分綁定您自己的 Resend 帳號，額度不與其他商家共用，寄件紀錄也完全由您掌控。不想自己管理，選寄信託管即可。

預估所需時間
自己申請約需 10 分鐘；提交後系統會自動驗證並寄一封測試信到您的信箱。選寄信託管則什麼都不用做，聯繫我們開通即可。

Step 1：註冊 Resend 帳號

Resend 是專業的寄信服務，免費方案就夠用

  1. 前往 resend.com，點擊 Sign up
  2. 用您的 Email 註冊（建議用下單時的同一個 Email）
  3. 到信箱點擊 驗證連結 啟用帳號
免費方案即可
Resend 免費方案每天可寄 100 封、每月 3,000 封，一頁式網站的訂單通知綽綽有餘，不需要付費升級。

Step 2：建立 API 金鑰

金鑰是網站代替您寄信的鑰匙

  1. 登入 Resend 後，點擊左側選單的 API Keys
  2. 點擊 Create API Key
  3. 名稱輸入好記的文字（例如 one-page-go），權限建議選 Full access
  4. 點擊 Create，立刻複製畫面上 re_ 開頭的完整金鑰
金鑰只會顯示一次
關閉視窗後就看不到完整金鑰了。如果忘了複製，直接刪掉重建一把即可，不影響任何東西。

Step 3：在網站上提交金鑰

系統會自動驗證，並寄一封測試信給您

  1. 前往 查詢訂單進度，輸入下單 Email 完成驗證登入
  2. 在您已付款的訂單卡片上找到「🔑 寄信設定」區塊
  3. 貼上 re_ 開頭的金鑰，點擊 提交驗證
  4. 系統會用您的金鑰寄一封測試信到您的信箱；收到即代表設定成功，畫面會顯示「已驗證」
金鑰的保存方式
金鑰以加密連線（https）傳輸並存放於您的商家專屬資料庫；畫面上只會顯示尾碼（例如 re_****ab12），不會回顯全文。想更換時到 Resend 後台重建一把再提交即可。

Step 4（進階）：驗證寄件網域

有自己網域的商家做這步，信才能寄給您的客戶

  1. 在 Resend 左側選單點擊 Domains → Add Domain，輸入您的網域（例如 mybakery.com）
  2. Resend 會列出幾筆 DNS 記錄（DKIM、SPF 等）
  3. 到您網域的 DNS 管理後台（購買網域的地方），照著把這幾筆記錄逐一新增
  4. 回到 Resend 點擊 Verify；狀態變成 Verified 即完成
還沒有網域？
未驗證網域的 Resend 帳號只能寄信給您自己的信箱，無法寄給您的客戶。網站正式對外前需要完成這步——沒有網域或不想處理 DNS，改用「寄信託管」方案即可，交付時我們也會再與您確認。

寄信託管是什麼？

不想申請帳號、不想動 DNS？交給我們

寄信託管月費
NT$199 / 月
  1. 不用申請 Resend 帳號 — 寄信由我們的帳號代管
  2. 不用驗證網域、不用動 DNS — 技術細節全部由我們處理
  3. 隨時可轉自管 — 之後想改用自己的金鑰，照「寄信設定」提交即可，當月結束託管
怎麼選？
願意花 10 分鐘照教學申請的，自己管完全免費；想省事、或沒有自己的網域，選寄信託管最單純。

如何開通

聯繫我們即可，不用在網站上操作

  1. 以下單時的 Email 來信，或透過 Line 聯繫我們，說明要開通寄信託管並附上您的訂單編號
  2. 我們確認後為您的專案開通，並回覆生效日期
  3. 費用採每月請款（目前未支援自動扣款），我們會每月寄送繳費通知
上線前必須二選一
寄信設定（自己的金鑰通過驗證，或開通寄信託管）完成前，網站無法正式上線——因為訂單通知與驗證碼都寄不出去。

資料庫要放哪裡？二選一

預設不用做任何事；重視資料主權可選自備

  1. 託管（預設，免費）
    您的商家專屬資料庫由我們建置與維運，含在方案內不另收費。訂單、會員資料可隨時完整匯出。不用做任何設定。
  2. 自備（進階選項）
    網站程式與資料庫全套部署在您自己的 Cloudflare 帳號——程式跑在您家、資料放在您家，我們只透過您授權的權限限縮 token 代為部署與維運。
怎麼選？
絕大多數商家選託管就好，零設定、免費。想要「就算哪天不合作，網站和資料都完整在我自己帳號裡」的商家，選自備。兩者功能與效能完全相同。

自備四步驟

約 10 分鐘；Cloudflare 免費方案即可

  1. 前往 cloudflare.com 註冊帳號（免費方案即可），完成 Email 驗證
  2. 建立權限限縮的 API token：右上角頭像 → My Profile → API Tokens → Create Token → 最下方 Custom token
  3. 權限（Permissions）加兩條，資源（Account Resources）選您的帳號：
    Account / Workers Scripts / Edit
    Account / D1 / Edit
    建立後立刻複製完整 token（只顯示一次）
  4. 到 查詢訂單進度 驗證登入，在訂單卡的「🗄️ 資料庫設定」點「改放自己的 Cloudflare 帳號？」，貼上 token 送出——系統會自動驗證 token 有效與權限，通過即顯示「已驗證」
token 是機密
token 以加密連線提交，畫面只顯示尾碼、不回顯全文；權限只限 Workers 與 D1，動不到您帳號的其他東西。想撤銷隨時到 Cloudflare 後台刪除該 token 即可。

設定完成確認清單

依您選的寄信方案，確認對應項目都已完成

路線 A：自己申請 Resend 金鑰（免費）

  • 已註冊 Resend 帳號並完成 Email 驗證
  • 已建立 re_ 開頭的 API 金鑰
  • 已在「查詢訂單進度」提交金鑰，畫面顯示已驗證
  • 已收到系統寄出的測試信
  • （有自己網域者）已在 Resend 完成網域驗證

路線 B：寄信託管（NT$199／月）

  • 已來信或 Line 聯繫開通，並附上訂單編號
  • 已收到我們的開通確認回覆

自備資料庫（選用；不選＝託管，免設定）

  • 已註冊 Cloudflare 帳號
  • 已建立含 Workers Scripts／D1 兩項 Edit 權限的 API token
  • 已在「查詢訂單進度」提交 token，畫面顯示已驗證

1. 品牌文案
店名、簡介、營業資訊、想放上網頁的文字

2. 商品或服務資料

常見問題

為什麼網站需要寄信功能？
您的網站會寄兩種信：客戶下單後的訂單通知，以及登入用的驗證碼。寄信設定沒完成，這兩種信都寄不出去，所以是上線前的必要步驟。
Resend 免費方案夠用嗎？
一般小型商家夠用：每天 100 封、每月 3,000 封。以一筆訂單寄 1–2 封信估算，每天可承接數十筆訂單。量更大時再升級 Resend 付費方案即可，網站不用改任何東西。
金鑰交給你們安全嗎？
金鑰以加密連線（https）提交，存放於您的商家專屬資料庫；畫面只顯示尾碼，不會回顯全文。金鑰只有寄信權限，拿不到您 Resend 帳號的其他控制權，而且您隨時可以在 Resend 後台刪除舊金鑰、重建一把再提交。
我沒有自己的網域，怎麼辦？
未驗證網域的 Resend 帳號只能寄信給您自己，無法寄給您的客戶。兩個解法：買一個網域（一年幾百元）照 Step 4 完成驗證，或選擇寄信託管（NT$199／月）由我們處理。交付時我們也會與您確認最適合的作法。
寄信託管和自己申請差在哪？
功能完全相同，差在誰管理：自己申請免費，但要註冊帳號、建金鑰，有網域的話還要設定 DNS；寄信託管 NT$199／月，全部由我們代管，您什麼都不用做。之後隨時可以互換。
日後不想用了，資料會怎樣？
您的訂單、會員等營運資料存放在商家專屬資料庫，隨時可以要求完整匯出（通用格式），資料完全屬於您。選「自備資料庫」的商家更直接：網站與資料本來就在您自己的 Cloudflare 帳號裡。Resend 帳號也是您自己的，金鑰刪除即失效。
資料庫可以放在我自己的帳號嗎？
可以。選「自備資料庫」，網站程式與資料庫全套部署在您自己的 Cloudflare 帳號（免費方案即可），我們只透過您授權的權限限縮 token 代為部署維運。作法見「資料庫設定」分頁；預設的託管方案則完全免設定、免費。
我完全不懂技術，能完成這些步驟嗎？
可以的！寄信設定只有「註冊、建金鑰、貼上提交」三步，系統會自動驗證並告訴您結果。遇到困難隨時聯繫我們，或直接選寄信託管，一步都不用做。
設定完成後多久網頁會上線？
素材齊全且寄信設定完成後，我們通常在 5–7 個工作天內完成製作與部署（依合約時程）。完成後會立即通知您，並附上您的網頁網址。
